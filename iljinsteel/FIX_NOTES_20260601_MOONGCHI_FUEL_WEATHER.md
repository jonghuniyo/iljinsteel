# 2026-06-01 뭉치/유가/생활날씨 수정

## 반영 사항
- 뭉치 픽셀 캐릭터를 우측 하단 플로팅 버튼 묶음 위로 이동
- 뭉치 클릭 시 뭉치 패널이 열리도록 인터랙션 추가
- 뭉치 움직임을 좌우 이동이 아닌 아주 작은 상하 idle 애니메이션으로 축소
- + 버튼과 맨 위로 버튼 크기/정렬 통일
- 왼쪽 탭 생활날씨를 우산/미세먼지 요약형으로 변경
- 생활날씨 지역 선택 옵션을 전국 주요 시도 + 마포/임실/수원으로 확대
- 메뉴명 `칸반 보드`를 `업무 보드`로 변경
- 푸터에 `Made by 이종훈` 문구 추가
- 오피넷 국내 휘발유/경유 평균가 환경변수 안내 강화
- OPINET_API_KEY 외 OPINET_CODE 환경변수명도 지원

## 국내 유가 표시 조건
국내 휘발유/경유 평균가격은 한국석유공사 오피넷 인증키가 필요합니다.
Netlify 환경변수에 `OPINET_API_KEY` 또는 `OPINET_CODE`를 등록하면 `avgAllPrice.do` API를 통해 평균가를 표시합니다.
