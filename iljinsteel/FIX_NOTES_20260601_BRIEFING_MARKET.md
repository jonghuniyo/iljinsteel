# 2026-06-01 브리핑/패널/시세 정확도 수정

## 반영 내용
- 오늘의 브리핑은 기본 열린 상태로 변경.
- 오늘의 브리핑에서 시세 동향/환율 동향 제거.
- 국내뉴스/해외뉴스 타이틀을 간단히 묶어 요약하는 문구 추가.
- 생활 날씨를 오늘의 브리핑 오른쪽으로 배치하여 상단 영역을 2분할.
- 우측 사이드패널에서 세계시각, 이번 주 식단표 카드, 바로가기 카드 제거.
- 우측 시세 카드 순서를 외환 시세 → 광물 시세 → 유가 시세로 변경.
- + 탭의 뭉치 > 사주 운세 클릭 시 빈 화면이 나오던 문제 수정.
- 광물 시세 전일대비 계산에서 Yahoo chartPreviousClose 사용을 중단하고 previousClose 또는 최근 종가 배열의 직전값을 사용.
- 외부 시세 API 실패 시 샘플 가격을 표시하지 않도록 변경.
- 광물 시세 카드에 “Yahoo 선물 참고값 · LME 공식값 아님” 안내 추가.

## 광물 시세 참고
현재 홈 광물 시세는 Yahoo Finance 선물 심볼 기반 참고값입니다. LME official cash/3M 가격이 필요한 경우 LME 공식 데이터 또는 라이선스 데이터 공급사 연동이 필요합니다.
